## 프로모션 텍스트 (170)

약 먹을 시간이 되면 알림으로 알려드려요. 알림에서 바로 "복용 완료"를 누르면 기록까지 끝. 로그인 없이, 모든 정보는 내 기기에만 저장돼요.

## 설명 (4000)

```
약챙김은 약 먹을 시간을 잊지 않게 알려주고, 먹었는지 간단히 기록하는 복약 알림 앱이에요.

■ 시간 맞춰 알림
약과 복용 시간을 등록하면 매일, 또는 정한 요일마다 알림이 와요.
하루에 여러 번 먹는 약도 시간마다 따로 알려드려요.

■ 알림에서 바로 복용 완료
알림의 "복용 완료" 버튼을 누르면 앱이 열리면서 바로 기록돼요.

■ 오늘 먹을 약을 한눈에
오늘 먹을 약을 시간순으로 보여주고, 몇 번 남았는지 알려드려요.
시간이 지났는데 아직 안 먹은 약은 따로 표시돼요.

최근 7일 복용률을 확인하고, 지난 날짜의 기록도 고칠 수 있어요.

회원가입과 로그인이 없어요. 입력한 정보는 기기에만 저장되고 외부로 전송되지 않아요.

■ 다크 모드 지원

※ 약챙김은 복약을 돕는 보조 도구이며 의학적 조언, 진단, 치료를 대체하지 않습니다.
복용량과 복용법은 반드시 의사·약사의 안내를 따라 주세요.
```

## 앱 개인정보 보호 (App Privacy)

- 데이터 수집 여부: **아니요, 이 앱에서 데이터를 수집하지 않습니다**
- 근거: 서버·네트워크 통신 없음, 광고·분석·충돌 리포트 SDK 없음 (pubspec.yaml 의존성 기준)

## 연령 등급

모든 문항 "없음" → 4+.
"의료 또는 치료 정보" 문항도 "없음" (약 정보·복용 지침을 제공하지 않고 사용자가 입력한 내용만 표시).

## 수출 규정

Info.plist에 `ITSAppUsesNonExemptEncryption = false`가 들어가 있어 업로드 때 질문이 생략된다.

## 계정 승인 후 남은 순서

1. Xcode → Settings → Accounts에 개인 Apple ID 로그인
2. Xcode에서 `ios/Runner.xcworkspace` 열기 → Runner → Signing & Capabilities → Team 선택
3. App Store Connect → 앱 → 신규 앱 (번들 ID `com.jua.pillCheck`, 위 정보 입력)
4. `fvm flutter build ipa`
5. `build/ios/ipa/*.ipa`를 Transporter로 업로드
6. 실기기에서 TestFlight로 알림·"복용 완료" 버튼 확인 후 심사 제출
